# 大肥鱼桌宠 · 独立便携版

基于 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 二次开发的 Windows 桌面宠物。保留原项目的透明动画和桌面互动，提供免安装 EXE 启动、离线台词、API 聊天和电子斗蛐蛐。

本项目是社区二次开发，与原项目维护者无隶属关系。桌宠基础实现与原角色动画来自原项目，感谢原作者的开源贡献。

## 下载与运行

前往 [Releases 下载 Windows 完整包](https://github.com/dzqy2004/dafeiyu-desktop-pet/releases/latest)，选择 `dafeiyu-desktop-pet-windows-x64.zip`。

1. 将压缩包完整解压到 D 盘一个文件夹。
2. 双击其中的 `大肥鱼桌宠.exe`。
3. 右键桌宠或托盘图标，可以打开设置与聊天、创建分身、选择动作或开始电子斗蛐蛐。
4. 退出请使用托盘菜单中的“退出大肥鱼”。

支持 Windows 64 位，已包含 Electron 运行环境，无需安装 Node.js、Python 或 DSH。EXE 与“资源”文件夹必须放在一起。请下载 Release 完整包；GitHub 的“Download ZIP”是开发源码包。

## 相对原项目的主要扩展

| 方面 | 本项目提供的改动 |
| --- | --- |
| 独立运行 | Windows EXE 便携启动器、托盘菜单、独立设置面板、可配置开机启动；运行环境随包附带 |
| 离线互动 | 5000 条完整本地短句，覆盖动作和待机话题；按动作、时段抽取并减少近期重复，支持本地表情包与独立开关 |
| 人设与聊天 | 统一鲸鱼娘人设，自称“我”、称用户“用户酱”；用户自填 API，桌面鲸鱼聊天框支持滚动、输入、复制与历史记录 |
| 活动设置 | 移动／动作／待机／转向权重面板，安静、均衡、巡游预设，上下及斜向漫游路线 |
| 余额展示 | 独立便携环境中的余额查询接入；金额或失败原因优先显示，自动短句不会覆盖查询结果 |
| 分身碰撞 | 重做普通模式的拖拽／抛掷碰撞协调：高速接触检测、推开、动量反弹与连锁响应，可保存开关 |
| 桌面乱斗 | 2～10 条鱼自动混战、10 种性格、仇恨与争食行为；暂停、继续、结束、排名、统计与饭碗榜 |
| 技能与事件 | 36 项战斗内容，含技能、大招及场外事件；技能图鉴、逐鱼自由配招、事件开关／频率及投放数量设置 |
| 本地数据 | API 密钥使用 Windows 当前用户保护机制；设置、聊天及战斗记录本地保存，发行包不含用户数据 |

106 个原角色动画、透明置顶、多开、点击反馈、拖拽抛掷、边缘反弹、动作菜单等基础能力来自原项目。原项目本身已有独立运行入口和可选宠物互撞；这里扩展的是 Windows 便携发布方式与普通分身碰撞的具体实现。比较基于本项目使用的 `dsh-pet 0.3.6`，原仓库后续变化请以原作者说明为准。

## 使用要点

- 日常台词与乱斗可离线使用；自由聊天及余额查询需要网络和你自己的 API 配置。5000 条短句是本地词库，不是在线模型对话记录。
- 右键“设置与聊天”→“API 与设置”可保存 API、台词、碰撞等选项；日常回复采用短句风格，详细说明、故事和代码可以完整回复。
- 右键“活动权重与活泼程度”可调整活动比例；取消“原地活动，暂不漫游”后才会自主移动。
- 右键“电子斗蛐蛐”，选择 2～10 条鱼，随机配招或逐鱼自选，再开始乱斗。战斗全程静音，鱼与特效鼠标穿透。
- 乱斗设置支持每条鱼 1～8 个普通技能、0～2 个大招；小鱼干和罐头每轮可选 1～12 份／个，地震作用于全场。
- 当前默认开启开机启动；可以在托盘菜单或设置中关闭。普通分身碰撞默认开启，拖拽和抛掷会触发碰撞。

更详细的步骤见 [使用说明](docs/使用说明.md) 与 [电子斗蛐蛐](docs/电子斗蛐蛐.md)。

## 数据与保存

在 D 盘运行时，用户数据位于 EXE 旁的“数据”目录。放在其他盘时，程序会使用 `D:\Codex\pets\大肥鱼完整版\数据`，因此本发布包建议在 D 盘运行。退出后再备份或迁移数据；请勿将“数据”目录上传到公开仓库。

## 开发与构建

仓库提供最终运行代码、C# 启动器源码、构建脚本和测试。原动画等未修改素材由构建脚本从固定版本 npm 包恢复，并核对散列；修改素材保存在仓库中。最终修改直接作用于运行代码，不依赖重新编译上游 TypeScript。

在 Windows 安装 Python 3.10+ 与 Node.js 后：

```powershell
python scripts/build.py
```

脚本恢复经过验证的 EXE 和固定版本 Electron，逐文件核对运行代码、素材与启动器，输出 `outputs/dafeiyu-desktop-pet-windows-x64.zip` 和 SHA-256 校验文件。缓存与临时文件位于仓库的 `work/`；首次构建需要联网。可用 `--cache-dir` 指定已有的下载缓存。`--rebuild-launcher` 使用 Windows 的 .NET Framework C# 编译器重编启动器；修改启动器源码后也会自动重编。

```powershell
node --test tests/collision.test.cjs
```

完整构建会在恢复原素材后运行 21 项普通碰撞测试与 28 项乱斗测试；上面的命令可单独运行碰撞测试。实际窗口检查覆盖 Windows 单屏 150% 缩放，多显示器几何以自动测试覆盖。十鱼乱斗使用多个 Electron 窗口，资源占用会随机器配置变化。
