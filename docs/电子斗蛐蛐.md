# 电子斗蛐蛐

在桌宠身体上右键选择“电子斗蛐蛐”，选择 2～10 条鱼，配置技能和事件，然后开始乱斗。倒数后所有鱼自动混战。小观战面板可暂停、继续、结束；战斗全程静音，鱼和特效鼠标穿透。

## 技能与事件

内置 36 项战斗内容，包括攻击、控制、防御／恢复、特殊技能、大招和三类场外事件；10 种性格，31 类 401 条事件台词。技能图鉴支持搜索、分类及查看实际数值和使用条件。

每条鱼可选 1～8 个普通技能与 0～2 个大招，支持随机配招、自选和批量复制。配置可保存，开战后暂时不能修改本局配置。

场外事件为天降小鱼干、桌面地震和巨型鱼罐头，支持分别开关、全部关闭与三档频率。小鱼干每轮 1～12 份、罐头每轮 1～12 个，默认各 3；地震作用于全体。罐头落点独立预警，鱼可以尝试躲开；地震只影响鱼和战斗效果，不移动其他软件窗口。

鱼根据挨打、控制、连续攻击积累仇恨，也会加入交战、寻找背后机会、争食、撤退和抢最后一击。普通对局默认 1000 HP。大量食物或纯恢复配招可能延长战斗。

## 结果与记录

淘汰鱼淡出，冠军保留胜利动作。结果面板支持滚动排名、展开统计与配招；最后两条鱼在同一步倒下会“双败”，并列第一且无冠军。“再来一局”开始新的随机对局；“结束乱斗”清理战斗窗口并恢复普通桌宠。

最近 100 局保存为“数据/battle-history.json”，饭碗榜按称号累计。折叠种子选项可以重放相似的随机过程；不同工作区和程序环境可能影响结果。

## 运行环境

十鱼乱斗会创建多个 Electron 窗口，性能取决于电脑配置。实际窗口检查覆盖 Windows 单屏 150% 缩放；多屏、负坐标、屏缝和工作区空洞以几何自动测试覆盖。
