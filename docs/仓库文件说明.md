# 仓库文件说明

| 路径 | 内容 |
| --- | --- |
| `README.md` | 项目介绍、功能扩展、下载入口、原项目来源与运行要求 |
| `docs/使用说明.md` | 桌面互动、离线台词、聊天、活动设置与数据保存 |
| `docs/电子斗蛐蛐.md` | 乱斗操作、技能配置、场外事件及结果记录 |
| `src/launcher/` | C# 启动器源码、图标及经过验证的 EXE |
| `src/pet/portable/` | 独立设置、API 服务、聊天外观和本地词库 |
| `src/pet/runtime/electron-helper/` | 桌面窗口、动画、普通分身碰撞与乱斗实现 |
| `src/pet/assets/battle/` | 扩展战斗素材与素材清单 |
| `scripts/build.py` | 恢复素材、校验运行文件、执行测试并生成便携完整包 |
| `scripts/*-manifest.json` | 运行代码、素材、Electron 与启动器的完整性清单 |
| `tests/` | 普通分身碰撞测试；乱斗测试随相应模块保存 |
| `LICENSE`、`licenses/` | 本项目许可、原项目与人设参考项目的原许可文本 |
| `THIRD_PARTY_NOTICES.md` | 原作者、项目出处及第三方许可位置 |
| `.github/workflows/release.yml` | Windows 完整包的构建与 Release 发布配置 |

原动画、字体和其他未修改原素材由构建脚本从固定版本 `dsh-pet@0.3.6` 获取，依据清单核对散列。源码包不附带完整 Electron 运行环境；普通使用请下载 Releases 的 Windows 完整包。

生成的 `work/`、`outputs/` 以及用户的“数据”目录不纳入 Git。完整发布包包含 EXE、资源和使用说明，用户首次运行后才生成个人数据。
