# 大肥鱼桌宠使用说明

完整解压到 D 盘后，双击“大肥鱼桌宠.exe”。EXE 与“资源”文件夹必须保持相邻，无需安装开发环境。程序的设置、缓存和记录在首次运行时生成。

## 桌面互动

点击桌宠触发对应动画与台词；按住拖动可搬动或推开分身，松手甩抛可产生碰撞与反弹。右键菜单可选择具体动作、创建或移除分身。透明画布边缘不作为鱼的实体碰撞区。

右键“设置与聊天”→“API 与设置”可关闭或开启“分身碰撞（拖拽／抛掷）”，点“保存这些设置”后持久生效。普通自主行走保留自己的行为规则；碰撞的主动来源为拖拽和抛掷。

## 台词与聊天

内置 5000 条完整短句，按动作和待机话题组织。点击、动作配词和自动碎碎念使用本地词库；可分别关闭，也可右键手动“说一句（本地）”。台词总开关在设置和右键菜单中均可使用。开启表情包后，部分短句按语境搭配本地图片。

自由对话需要在设置填写自己的 API 地址、模型与密钥。日常聊天采用鲸鱼娘的短句人设；需要详细说明、故事或代码时允许长回复。桌面气泡正文最多四行，完整回复保存在鲸鱼聊天框及聊天记录中。Enter 发送，Shift+Enter 换行，支持滚动与复制。

API 密钥通过 Windows 当前用户保护机制保存。聊天请求会发送到你配置的 API 服务。本地台词和乱斗不调用聊天 API。

## 活动与余额

右键“活动权重与活泼程度”可调移动、动作、待机、转向比例，也可选安静、均衡、巡游预设。默认权重为 48%／32%／12%／8%。取消“原地活动，暂不漫游”后自主移动；聊天时暂缓漫游。

余额查询依赖支持的服务与自己的凭据。金额或查询失败原因优先展示，自动台词不会覆盖；余额显示与工作提示可分别关闭。

## 数据与退出

使用托盘菜单“退出大肥鱼”结束程序。默认开机启动可在托盘或设置中关闭。

D 盘运行时数据位于 EXE 旁的“数据”目录；其他盘运行时使用 `D:\Codex\pets\大肥鱼完整版\数据`。API 设置在 `api-settings.json`，聊天记忆在 `dsh-pet/memory.json`。同一 Windows 账户可在程序关闭时备份或迁移。不要用其他配置整体覆盖默认人设与活动设置。发行包不包含密钥、聊天记录或个人配置。
