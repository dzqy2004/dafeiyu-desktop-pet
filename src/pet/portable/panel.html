完整配置

动画池、播放权重、物理参数、人设、独立模型和额外宠物素材配置，都可以在这里调整。使用 JSON 格式。

额外宠物与自定义动画

主宠物素材放到「数据/dsh-pet/main-animation/webm」；额外宠物在「数据/dsh-pet/pet」放入对应的配置文件和动画目录。桌宠仍使用原项目的素材链与透明 WebM 格式。

本地词库覆盖所有内置动作、待机和生活场景。修改 API 对话人设不会自动改写本地台词。
